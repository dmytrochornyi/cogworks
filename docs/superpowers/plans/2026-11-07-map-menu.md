# Map menu

A full-window world map, opened from the game. No fast travel, map markers set by the player, fog of war or simulation changes.

**Rules**

- Keep saves compatible; nothing new is saved.
- No film grain or paper noise. Do not change the lighting.
- Put layout and coordinate maths in pure functions with unit tests, as `research_layout` does.
- `cargo test` and `cargo clippy --all-targets` must pass with zero warnings.
- Never run the game from the repo root without `COGWORKS_SCREENSHOT`: it would write over the user's saves.

## Behaviour

1. **Opening and closing.** N toggles the map, like E and T toggle their windows. Clicking the minimap opens it, only when `hud_active()` is true. Esc and the close button close it. The world keeps running, as with other windows.
2. **Window.** `Panel::Map` in `src/game.rs`, drawn by a new `src/ui/panels/map.rs` using the shared `Panel` widget, titled "Map" with the existing slide-in. It is centred and fills the window up to `2 * space::L` margins: a square map on the left, sized from the available height and width, and a legend column on the right.
3. **Map image.** Reuse the minimap's texture so there is one raster. Do not add a second refresh.
4. **Markers.** Draw over the image, clipped to it:
   - player, as on the minimap;
   - the camera's view rectangle;
   - hives, as larger circles in the hive colour, since a 3x3 hive is only a few pixels;
   - enemies, as small dots, skipped in peaceful mode only if none exist.
   Share player and view-rectangle drawing with the minimap through one helper.
5. **Legend.** One swatch and name per row, using the colours the map really uses: each ore, tar, buildings, hives and enemies, plus the player marker. Below it, the counts "Buildings: N" and "Hives: N".
6. **Hover.** Hovering the map shows the existing tile tooltip for the tile underneath (`describe_rows`, `describe_icon`). Clicking the map does nothing.
7. **Discoverability.** The minimap shows a tooltip "Map · N or click" when hovered. Add N to the help note without widening it past `HELP_MAX_TEXT_W`, and to the README controls table and features list.
8. **Dev aid.** `COGWORKS_PANEL=map` opens it in screenshot mode. Add it to the README's list if panels are named there.

## Tests

- Layout: the map stays square and on screen, and the legend stays inside the window, at 1440x900, 1920x1080, 1250x775 and a narrow 820x900 logical size.
- Coordinates: screen-to-tile mapping gives (0,0) at the top-left, (255,255) just inside the bottom-right, and `None` outside the map.
